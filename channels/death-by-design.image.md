# Death by Design — image rule

Follow this STRICTLY for every image. This channel is a serious explainer, not a cartoon.
The frames must look like slides from a briefing, not like doodles.

Generate EXACTLY ONE image per beat, named `beat<NN>_<label>.png`.

## Canvas

- 16:9, landscape.
- Background: near-black (#0b0b0d). Never white, never a gradient, never a photo.
- Flat vector look. No 3D renders, no lens flares, no drop shadows, no textures.

## Palette — only these

- **Amber / orange** — the dangerous quantity, the failing system, the number that matters.
  Use it for exactly one thing per frame. It is the eye's target.
- **Pale blue** — the safe state, the normal condition, the working system.
- **White** — labels, outlines, axes.
- **Grey** — everything secondary.

Never introduce a fifth colour. Never make a frame mostly amber — the accent only works
because the rest of the frame is quiet.

## What each frame contains

One idea. If two things are being compared, show both halves of the comparison and nothing
else. Preferred forms, in order:

1. **Cross-section diagram** — skin, a wall, a lung, a pipe — with labelled arrows showing
   where heat, air, water or force is actually going.
2. **Before / after pair** — the working case beside the failing case, same framing both
   sides so the difference is the only thing that changed.
3. **Single big numeral** with its unit, when the narration names a figure. The number fills
   the frame. A three-word caption underneath at most.
4. **Instrument or gauge** — thermometer, dial, meter — reading a specific value.
5. **Single-line human silhouette** — no face, no expression, no clothing detail. A body is
   a system in this channel, not a character.
6. **Simple map or region shape** when a place is named. Outline only, one region highlighted
   in amber.

## Text in frame

- Two or three words maximum. Labels, not sentences. `WET BULB 35°C`, `NO EVAPORATION`,
  `AIR 42°C`.
- Clean sans-serif, all caps, wide letter spacing.
- Units always attached to numbers.
- Never write out the narration. Never add a title card except where the beat is explicitly
  the opening.

## Hard bans

- No cartoons, mascots, stick figures, emoji, speech bubbles, or clip art.
- No smiling or distressed faces. No people as characters.
- No photorealism, no stock-photo look, no watermarks.
- No cluttered dashboards or fake UI.
- No arrows or labels that don't correspond to something the narration said.

## Continuity

Every frame in a video must look like it came from the same deck: same background, same
palette, same line weight, same label style. A viewer scrubbing the timeline should not be
able to tell where one section ends and another begins from the art style alone.
