You are going to generate images for a YouTube script.

Your job is to read the script carefully and create visual frames that match the narration.

IMPORTANT PACING RULE:
Do not only create one image per timestamp if the narration contains multiple ideas.

Generate at least one image for every beat in the script. However, if a beat contains multiple visual ideas, split that beat into multiple separate images. Each image should show only ONE clear idea.

The goal is fast-paced YouTube editing, so create a new visual whenever the viewer’s attention should refresh. Aim for a visual change every 1 to 2 seconds.

VISUAL BEAT RULES:
Create extra images whenever the narration contains:
- a list of things
- a comparison
- a cause and effect
- a scientific object or term
- a discovery or piece of evidence
- an emotional moment
- a question
- a transition to a new idea

Do not squeeze multiple ideas into one image.

For example:
If the narration says “gestures, sounds, symbols, and music,” create separate visuals for:
1. gestures
2. sounds
3. symbols
4. music

If the narration says “A low larynx is dangerous because humans can choke,” create separate visuals for:
1. low larynx diagram
2. danger warning
3. choking stickman

Each image must visually illustrate what the narrator is saying at that exact moment. The image should make sense with the story, the emotion, and the idea being explained. Do not create random images.

STYLE REQUIREMENTS:
The image style must look like extremely simple beginner drawings made in MS Paint.

It should look like someone who is not good at drawing created it quickly by hand.

Use a very simple stickman / childish drawing style:
- White background
- Thick, uneven black outlines
- Wobbly hand-drawn lines
- Stick figure humans with round heads and line bodies
- Simple dot eyes or circle eyes
- Very basic facial expressions
- Flat colors only
- No realistic shading
- No 3D
- No cinematic lighting
- No realistic cartoon style
- No Disney style
- No anime style
- No polished illustration style
- No professional vector art
- No highly detailed backgrounds
- No complex textures
- No realistic humans
- No glossy or modern design

The drawings should feel amateur, funny, simple, and intentionally “bad,” like a noob drew them in Paint.

Objects should be drawn with basic shapes:
- squares
- circles
- rectangles
- arrows
- simple tables
- boxes
- trees
- rooms
- signs
- screens
- stickmen
- question marks
- simple symbols

Use the same visual language throughout:
- Simple black line drawings
- Mostly white empty space
- Occasional flat colors like green, brown, gray, red, yellow, orange, and blue
- Red arrows or red question marks when needed
- Handwritten text only when it helps explain the idea

TEXT RULES:
If text appears in the image:
- Keep it very short
- Spell it correctly
- Make it easy to read
- Do not add long sentences
- Do not put too many labels in one frame

FORMAT REQUIREMENTS:
Every image must be horizontal 16:9 for YouTube video format.

Generate each image as a wide YouTube frame:
- Not vertical
- Not square
- Clean and readable
- Centered composition
- Do not crop important objects
- Leave enough space around characters and objects

Avoid:
- glitches
- broken anatomy
- unreadable text
- messy overlapping objects
- weird extra details
- images that look too polished
- images that look professional
